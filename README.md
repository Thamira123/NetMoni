# NetMoni
## Distributed Network Device Monitoring System

NetMoni is a real-time distributed network monitoring application developed using Java and JavaScript.

## Run the complete system

The agent, PostgreSQL-backed Spring Boot server, and React dashboard are connected through TCP, REST/WebSocket, and PostgreSQL. Follow the [complete local setup guide](docs/local-development.md) to start them in order and connect a monitored device to an agent.

### Main Components
- Network Monitoring Agent
- Central Monitoring Server
- Web Dashboard
- PostgreSQL Database

### Technologies
- Java
- Spring Boot
- React
- PostgreSQL
- TCP Sockets
- ICMP
- SNMP
- WebSocket
